# @effect-kit/storage

Effect-native object storage services and workflows.

This package is under development and has not been published by this project work.
Requires Effect within the declared peer range; workspace tooling uses Node from
`.node-version` and pnpm from the root `packageManager`.

Product documentation, API guides and runnable examples belong to the separate
landing-page repository. This repository contains the library, tests and tooling.
Local design/research material is ignored and is not a build or CI input.

For repository development and verification commands, read the root README.
Provider SDKs and runtime integrations remain optional, isolated package entry points.
Local protocol acceptance does not establish hosted-provider qualification.
