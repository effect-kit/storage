Initial release of Effect Kit Storage for Effect 4.1.

- Portable storage services, scoped streaming, conditional operations, typed errors,
  capability contracts, memory storage and adapter conformance tools.
- Optional AWS S3, R2, MinIO, Tigris, Spaces, B2, Wasabi, Scaleway, Hetzner,
  GCS, Azure, Supabase, Vercel Blob and filesystem integrations.
- Managed transfers, integrity verification, resource budgets and protected durable
  upload/download sessions backed by Effect persistence.
- Signing, authorized browser uploads, HTTP integration, upload atoms and React hooks.
- Lifecycle and event services, composition and caching, migration and mirroring,
  content addressing, gzip and optional age encryption.
- Isolated Node, Bun, Deno and browser runtime entry points.
